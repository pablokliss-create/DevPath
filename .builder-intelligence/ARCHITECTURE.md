# Architecture

- Next.js + React + TypeScript form the current web foundation.
- Course content, progress, exercises, runner, and UI should remain separable enough to evolve independently.
- Do not rewrite the stack because a newer framework exists; require measurable benefit and migration justification.
- External services must be introduced only when the product actually needs them.
- Keep data/content portable where practical so a future technology change does not force a full rewrite.
- Repository state and passing tests outrank stale architectural descriptions.
