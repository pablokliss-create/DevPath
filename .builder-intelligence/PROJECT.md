# DevPath

## Purpose
DevPath is a programming-learning platform for people who have already tried to learn and failed. Its core goal is to build reasoning and mental models rather than syntax memorization.

## Pedagogical invariants
- Progress is measured by demonstrated mental models.
- Preferred progression when appropriate: see -> predict -> trace -> complete -> fix -> modify -> rebuild -> create -> transfer.
- Use worked examples, faded examples, tracing, gradual scaffolding removal, and cumulative review.
- Introduce abstractions only after the learner understands what they hide.
- Mastery requires explaining, predicting, diagnosing, modifying, and transferring.

## Current state
The technical foundation exists, but the curriculum is still early relative to the full product vision. Treat the repository as platform foundation + early curriculum, not a nearly-finished course.
