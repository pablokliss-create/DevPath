# QA Rules

Before merging material changes:
- run unit/component tests;
- run content validation when course content changes;
- run targeted E2E for affected user flows;
- test PT-BR/EN when copy/navigation changes;
- check mobile/responsive behavior for UI changes;
- verify accessibility-sensitive interactions;
- record regressions and durable lessons.

Do not infer correctness from a successful build alone.
