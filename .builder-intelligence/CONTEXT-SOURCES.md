# Context Sources

Use sources in this order when they conflict:
1. Current executable/tested repository state.
2. Explicit latest user decision.
3. Shared canonical Builder Intelligence / project context.
4. Current official docs/releases for external technology facts.
5. Older chat memory or inferred context.

Shared technical intelligence should be pulled from the canonical Builder Intelligence Shared repository once available. Personal project memory must not be exported to the shared repository.
