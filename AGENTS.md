# DevPath Agent Bootstrap

Before changing this repository, load the project context from `.builder-intelligence/`.

Required order:
1. Read `.builder-intelligence/PROJECT.md`.
2. Read `.builder-intelligence/ARCHITECTURE.md` and `DECISIONS.md`.
3. Check `KNOWN-ISSUES.md`, `QA.md`, and `CONTEXT-SOURCES.md`.
4. Inspect the real repository state before making assumptions.
5. Revalidate volatile external facts such as versions, security notices, pricing, or compatibility.
6. Run the relevant tests before and after material changes.
7. Record durable decisions and lessons instead of relying on chat memory.

Global rule: no tool, framework, plugin, Skill, MCP, or service is an automatic default. Choose by current fit, evidence, migration risk, portability, security, and total cost.

Canonical project name: `DevPath`.
Legacy project `curso-programacao-nu` is not DevPath and must not be used as current project context.
